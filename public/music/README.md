# Music

Place your file here:

```
happy-birthday-pop.mp3
```

The site uses the song **Happy Birthday Pop** from this exact path
(`/music/happy-birthday-pop.mp3`).

If the file is not present, the website keeps working perfectly and
falls back to a soft, gentle built-in melody (a quiet music-box
arrangement of the public-domain “Happy Birthday” tune) so the surprise
still feels complete. No broken controls, no errors.
